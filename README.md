A chess engine in 4 KB of Python: 120-square mailbox board, piece-square
evaluation tapered by game phase, alpha-beta with transposition table,
null move, late move reductions, futility pruning, killer and history
ordering, quiescence search. Fixed node budget, no clock in the search,
so every move is reproducible. Board representation idea credited to
sunfish (Thomas Ahle); the code is original.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
